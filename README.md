# Contact Manager Overview
Our project is a Contact Manager. This is a place where you can store your contacts. Some of the features of the Contact Manager are that we have a dashboard to show all the contacts that you have stored. In the dashboard, we have an for adding a contact in which you can add their first and last name, birth year, type of contact, their mobile or home phone, personal or business email, home or work address, and a note to put in for that contact. The dashboard will tell you how many contacts you currently have stored. You can search for a certain contact or sort the contacts alphabetically or reverse alphabetically in the dashboard as well. We also have an account settings section in the dashboard where you can change your username and password if desired. We also have a logout button in the dashboard to log out of your account after you're done using the Contact Manager.

# How to run the Contact Manager
First, you should clone the repository to a code editor of your choice, such as VS Code or your computer's terminal. If you do not have Node.js installed can install Node.js by clicking on this link: https://nodejs.org/en, then click “Download Node.js (LTS)", after the package file downloads, click on it and follow the instructions from there. If you already have Node.js installed, you can skip the download and installation steps for Node.js. The dependencies for this web application are already in the GitHub repository in the “node_modules” folder, but before running the application, make sure to run “npm install” to ensure that the correct dependencies are installed. To access our website application, open the terminal in your code editor or the terminal that you cloned the repository in, and type "node server.js." It should give you a link that you can click on to access our website. This link will take you to the login page of our website, the set username is "admin", and the set password is "1234". You can change the password after logging in by clicking on account settings on the dashboard page.
